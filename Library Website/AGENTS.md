# Academic Library Website

Create a professional and modern academic library website landing page 
for National Forensic Sciences University (NFSU). Use the logo file 
'nfsu_logo.png' available in the working directory.

## Design Requirements:

### General:
- Single HTML file (index.html) with embedded CSS and JavaScript
- Fully responsive design (mobile, tablet, desktop)
- Clean, professional, and academic look and feel
- Color scheme: Use color scheme based on the logo color. Use bright color only.
- Font: Use Google Fonts - 'Roboto' or 'Open Sans'

### Header Section:
- Display the NFSU logo (nfsu_logo.png) on the left side
- University name "National Forensic Sciences University" 
  prominently displayed
- Library name "Central Library" below the university name
- Navigation menu with the following links:
  * Home
  * About Library
  * Catalogue (OPAC)
  * E-Resources
  * New Arrivals
  * Services
  * Contact Us

### Hero/Banner Section:
- Full-width banner with a relevant background 
  (use CSS gradient if no image is available)
- Welcome message: "Welcome to NFSU Central Library"
- Tagline: "Your Gateway to Knowledge and Research"
- A Search Bar in the center with placeholder text 
  "Search Books, Journals, Articles..." 
  and a Search button
- Quick links below the search bar:
  * OPAC
  * E-Journals
  * E-Books
  * Databases

### Marquee/Notice Section:
- A scrolling marquee or animated ticker below the hero section
- Sample notices like:
  * "New arrivals added to the library collection - 
     Visit New Arrivals section"
  * "Library will remain closed on National Holidays"
  * "E-Resources accessible 24x7 through library portal"

### Quick Access / Services Section:
- Display service cards in a grid layout (3 or 4 columns)
- Each card should have an icon, title, and short description
- Include the following service cards:
  * Book Catalogue (OPAC)
  * E-Journals & Databases
  * E-Books
  * Research Support
  * Library Membership
  * Printing & Scanning
  * Reading Room
  * Remote Access

### Single Search
  * Search option which facilitate to search with in Library Catalogue, Institutional Repository, e-Resouces etc.

### Statistics Section:
- Display library statistics in a horizontal banner:
  * Total Books: 25,000+
  * E-Journals: 5,000+
  * E-Books: 10,000+
  * Members: 3,000+
- Use animated counter if possible (JavaScript)

### New Arrivals Section:
- Display sample new arrival book cards in a horizontal 
  scroll or grid (at least 4-6 sample cards)
- Each card should show:
  * Book cover placeholder (use colored div or placeholder image)
  * Book Title
  * Author Name
  * Year of Publication
  * "View Details" button

### E-Resources Section:
- Display logos/buttons for popular academic databases and 
  e-resources such as:
  * JSTOR
  * ScienceDirect
  * Springer
  * IEEE Xplore
  * NDLI (National Digital Library of India)
  * Shodhganga
  * Manupatra (for legal resources)
- Each should be displayed as a clickable card/button

### Library Timing Section:
- Display a clean table or card showing library working hours:
  * Monday to Friday: 8:00 AM - 8:00 PM
  * Saturday: 9:00 AM - 5:00 PM
  * Sunday: Closed
  * Holidays: Closed

### Notice Board / Announcements Section:
- Display 3-5 sample announcements with date and title:
  * Date badge on the left
  * Announcement title and short description on the right
  * "Read More" link

### Contact Section:
- Library address, phone number, email
- Use placeholder details relevant to NFSU:
  * Address: National Forensic Sciences University, 
    Sector 9, Gandhinagar, Gujarat - 382007
  * Phone: +91-79-XXXXXXXX
  * Email: library@nfsu.ac.in
  * Working Hours display

### Footer Section:
- NFSU Logo (small) on the left
- Quick links in the center
- Social media icons (Facebook, Twitter, LinkedIn, YouTube)
- Copyright text: 
  "© 2025 National Forensic Sciences University. 
   All Rights Reserved. | Central Library"

## Technical Requirements:
- Single self-contained HTML file (index.html)
- Embedded CSS (inside <style> tag) - No external CSS framework
- Embedded JavaScript (inside <script> tag)
- Use Font Awesome CDN for icons
- Use Google Fonts CDN for typography
- Smooth scrolling behavior
- Hover effects on cards and buttons
- Mobile hamburger menu for responsive navigation
- Sticky/fixed header on scroll
- Back to top button
- All links should be placeholder (#) since this is a 
  landing page prototype

## Output:
- Single file: index.html
- The file should be ready to open directly in any 
  web browser without any additional setup
- Ensure the nfsu_logo.png is referenced correctly 
  as it is in the same directory as index.html
- Open the file index.html after the process completed
