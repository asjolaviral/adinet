# Install OpenCode
Step-1: Open website https://opencode.ai/

Step-2: Click on **Download** button

<img src="/images/01.png" width="800">

Step-3: Complete the installation steps and launch the OpenCode Application from Desktop shortcut or from Start Menu

<img src="/images/02.png" width="400">

Step-4: The Application Screen

<img src="/images/03.png" width="800">

Step-5: Browse the website https://opencode.ai/ and click on **Zen**

<img src="/images/04.png" width="800">


Step-6: Click on **Get started with Zen**

<img src="/images/06.png" width="800">

Step-7: Click on **Continue with Google** and Sign in using your Google account

Step-8: After login click on **API Keys** and **Create API Key** and give appropriate key name and hit **create** button

<img src="/images/08.png" width="800">

Step-9: Copy the newly generated API Key

<img src="/images/09.png" width="800">

Step-10: Come back to OpenCode Application screen and click on **Manage Models** 

<img src="/images/10.png" width="800">

Step-11: Click on **Connect Provider** 

<img src="/images/11.png" width="800">

Step-12: Click on **OpenCodeZen** 

<img src="/images/12.png" width="800">

Step-13: Paste the newly generated API Key and click on **Continue** 

<img src="/images/13.png" width="800">
